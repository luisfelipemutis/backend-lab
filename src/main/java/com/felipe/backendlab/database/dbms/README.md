# DBMS - Database Management System

## ¿Qué es un DBMS?

Es un software que gestiona la creación, manipulación y acceso a bases de datos.

## Tipos de DBMS

### Relacional (SQL)
- MySQL
- PostgreSQL
- Oracle
- SQL Server
- **Ventajas**: Estructura clara, relaciones entre tablas, ACID compliance

### NoSQL
- MongoDB (Documentos)
- Redis (Clave-valor)
- Cassandra (Series temporales)
- **Ventajas**: Escalabilidad horizontal, flexibilidad
